# Klar NLU Fork (LLM-Fragen)

Fork der Klar-Engine: offene Weltfragen gehen an das unter **Settings → LLM**
konfigurierte Modell (z. B. LM Studio), statt „nicht verstanden“.

## Setup

1. Offizielle **Klar NLU**-App stoppen.
2. Dieses Add-on starten.
3. HACS-Integration URL: `http://klar-nlu-fork:10520`
4. LLM in der Fork-UI erneut prüfen (Settings → LLM).

Siehe Repo-Datei `DEPLOY-HAOS.md`.
